## Лабораторна робота №1. Фронтенд

**Варіант №12**

**Тема:** Реєстр програмного забезпечення для лабораторій
**Ключова сутність:** Програмний продукт (`Software Products`)

**Опис проєкту:**
Веб-застосунок для створення та керування каталогом програмного забезпечення для лабораторій. Реалізовано CRUD-операції, валідацію та збереження даних у браузері.

**Функціонал:**
* Створення нових записів про програмні продукти
* Відображення списку програм у вигляді таблиці
* Редагування записів про ПЗ
* Видалення записів
* Вибір типу ліцензії програми
* Валідація обов’язкових полів форми (Name, Version, LicenseType, Seats, Comment)
* Пошук по програмних продуктах
* Сортування по колонках
* Перемикання сортування (включення/вимикання)
* Підсвітка активної колонки сортування
* Захист від дублювання програмних продуктів
* Збереження даних у localStorage
* Автоматичне відновлення даних після перезавантаження сторінки

**Запуск проєкту:**
* Запуск локального сервера: `python -m http.server 8000` (або порт `8080`)
* Відкриття у браузері: `http://localhost:8000/`


## Лабораторна робота №2. Бекенд без БД

**Варіант №12**

**Як запустити бекенд:**
* Відкрийте термінал і перейдіть у папку бекенду: `cd backend`
* Встановіть залежності: `npm install`
* Запустіть сервер у режимі розробки: `npm run dev`
* Сервер запуститься за адресою: `http://localhost:3000`

**Реалізовані сутності:**
* `Users`: (id, name, email)
* `Software`: (id, name, version, developer)

**Реалізовані можливості:**
* REST API без бази даних
* Зберігання даних в оперативній пам’яті (In-Memory)
* DTO (Data Transfer Object)
* Middleware logger
* Centralized error handler
* Валідація запитів
* Pagination
* Filtering
* Sorting
* PATCH метод

**Приклади запитів (cURL):**
* Створити нового користувача (Успіх - 201 Created):
  ```bash
  curl -i -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d "{\"name\":\"Test\",\"email\":\"test@mail.com\"}"

Додати новий програмний продукт (201 Created):

Bash
curl -i -X POST http://localhost:3000/api/software -H "Content-Type: application/json" -d "{\"name\":\"IntelliJ IDEA\",\"version\":\"2024.1\",\"developer\":\"JetBrains\"}"

Отримати список користувачів (200 OK):

Bash
curl -i http://localhost:3000/api/users

Помилка валідації (400 Bad Request):

Bash
curl -i -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d "{\"name\":\"\"}"

Лабораторна робота №3. SQLITE: Реляційна модель, схема даних, CRUD-запити, підключення SQLITE у бекенд

Варіант №12

Як запустити бекенд:

Відкрийте термінал і перейдіть у папку бекенду: cd backend

Встановіть залежності: npm install

Запустіть сервер у режимі розробки: npm run dev

Сервер запуститься за адресою: http://localhost:3000

При першому запуску автоматично створиться файл data/app.db, застосуються міграції та база заповниться стартовими даними (Seed).

Схема бази даних (взаємопов'язані таблиці з ON DELETE CASCADE):

Users: (id, email UNIQUE, name, createdAt)

Software: (id, name, version, developer)

Licenses: (id, softwareId FOREIGN KEY, licenseKey, status, validUntil)

Реалізовані можливості:

Автоматична ініціалізація бази даних та створення таблиць (db.js, dbClient.js, initDb.js).
Механізм Seed (seed.js) для автоматичного наповнення бази тестовими даними (користувачі, стартові програми та ліцензії).
Тришарова архітектура (робота з БД винесена в окремий шар Repositories: Routes -> Controllers -> Repositories).
Складні SQL-запити: використання JOIN для об'єднання даних (ендпойнт GET /api/software повертає каталог програм).
Обмеження на рівні бази даних: унікальність (UNIQUE), зв'язки ключів та індекси.
Примітки щодо безпеки (SQL Injection):
Згідно з навчальною метою лабораторної роботи, фільтрація та сортування в деяких запитах реалізовані через конкатенацію рядків. Це робить систему вразливою до SQL Injection. Наприклад, передача ' OR 1=1; -- у параметри пошуку дозволяет обійти логіку вибірки. Вразливості будуть усунені в наступних роботах за допомогою параметризованих запитів.

Приклади запитів (cURL):
Отримати весь список програмного забезпечення (Складний запит з JOIN - 200 OK):

Bash
curl -i http://localhost:3000/api/software

Створити нову ліцензію в базі даних (201 Created):

Bash
curl -i -X POST http://localhost:3000/api/licenses -H "Content-Type: application/json" -d "{\"softwareId\":1,\"licenseKey\":\"AAAA-BBBB-CCCC-DDDD\",\"status\":\"active\",\"validUntil\":\"2027-12-31\"}"

Отримати користувачів з фільтрацією та сортуванням (200 OK):

Bash
curl -i "http://localhost:3000/api/users?sort=name&order=DESC"

Видалити програмний продукт та каскадно всі пов'язані ліцензії (200 OK):

Bash
curl -i -X DELETE http://localhost:3000/api/software/1
